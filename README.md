# DevCore — Agency Landing Page

Landing page for a software and design agency, with an animated shape hero,
scroll-driven container animations and a services section.

## Sections

- Animated hero with gradient/grid background
- Services overview
- Scroll-animation showcase
- Contact call to action

## Stack

React · TypeScript · Vite · shadcn/ui · Tailwind CSS

Originally scaffolded with [Anima](https://animaapp.com/).

## Running locally

**Prerequisites:** Node.js 18+

```bash
npm install
npm run dev     # http://localhost:5173
```

| Command | What it does |
|---|---|
| `npm run dev` | Vite dev server |
| `npm run build` | Production build to `dist/` |
